# The Giggle Circus

A colourful, responsive, static HTML/CSS/JavaScript concept website for children's clown entertainment and party bookings.

Deploy to Cloudflare Pages: no build command; output directory `/`.

Before launch: replace the demo booking email (`hello@example.com` in `script.js`), confirm real company name, packages and service area, and connect a real form backend if desired. All visuals are native CSS illustrations; no image assets required.
